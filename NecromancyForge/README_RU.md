# Некромантия — Forge 1.20.1

Небольшой исходный проект мода для Minecraft Java Edition 1.20.1, Forge 47.2.0, Java 17.

## Возможности
- **Посох некроманта**: ПКМ призывает скелета рядом с игроком, расходует 1 пойманную душу и 1 прочность посоха. Перезарядка — 4 секунды.
- **Пойманная душа**: расходуемый магический ресурс.
- **Алтарь некроманта**: ПКМ по алтарю с гнилой плотью превращает 1 гнилую плоть в 1 душу.
- Русские и английские названия, рецепты крафта.

## Сборка
1. Установите **JDK 17** и **Gradle 8.x**.
2. Распакуйте архив.
3. В папке проекта выполните `gradle build`.
4. Готовый JAR появится в `build/libs/`.
5. Переместите JAR в папку `.minecraft/mods`. На клиенте должен быть установлен Forge 1.20.1.

## Рецепты
- Посох: душа + 2 кости по диагонали.
- Алтарь: 5 обсидиана, око Эндера и 3 костных блока.

## Важно
Это стартовая версия 1.0.0. Призванный скелет пока является обычным скелетом Minecraft, а не отдельным приручаемым типом существа. Текстуры предметов `soul` и `necromancer_staff` нужно добавить в `assets/necromancy/textures/item/` (PNG); без них предметы будут с фиолетово-чёрной заглушкой. Модель алтаря использует текстуру плачущего обсидиана.
